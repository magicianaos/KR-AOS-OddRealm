  Odd Realm 한글패치 — 이 폴더가 전부입니다

  bat 3개     내가 쓰는 것
  배포 폴더    남들에게 나눠줄 것
  tool 폴더    번역 데이터와 빌드 도구

  이게 다입니다.


■ 하고 싶은 게 뭔가요?

  내 PC에 한글패치를 깔고 싶다
      "1. 한글패치 설치.bat" 더블클릭

  영어로 되돌리고 싶다
      "2. 원본으로 되돌리기.bat" 더블클릭

  번역을 고쳐서 새 버전을 만들고 싶다
      "3. 번역 고치고 다시 만들기.bat" 더블클릭
      (Python 이 필요합니다. 없으면 어디서 받는지 알려줍니다)
      다 끝나면 "배포" 폴더의 파일이 자동으로 최신으로 바뀝니다

  남들에게 배포하고 싶다
      배포\MEGA 올리는 방법.txt 를 보세요


■ 배포 폴더에 뭐가 있나요

  유저에게 줄 파일 3개입니다. 유저는 이 중 하나만 받으면 됩니다.

  OddRealm_한글패치_v1.0.3.exe            3.5MB
      받아서 더블클릭. 대부분 이걸 받습니다.
      게임 폴더 자동 탐색, 버전 확인, 원본 백업, 되돌리기까지 됩니다.

  OddRealm_한글패치_v1.0.3_직접교체용.zip  8.7MB
      실행 파일이 하나도 없습니다.
      압축 풀어서 게임 폴더에 덮어쓰면 끝입니다.
      프로그램 실행을 꺼리는 유저용이고, 어떤 저장소에도 걸리지 않습니다.

  OddRealm_한글패치_v1.0.3_스크립트판.zip  0.5MB
      ps1 우클릭 -> PowerShell에서 실행.
      설치 과정을 직접 읽어보고 싶은 유저용입니다.

  MEGA 올리는 방법.txt              배포 절차
  배포글 (복사해서 붙여넣기).txt     카페에 올릴 글 초안


■ 배포는 왜 MEGA 인가요

  구글 드라이브는 올린 파일을 검사해서 서명 없는 설치기를 지웁니다.
  exe, bat+ps1, ps1 단독 — 세 가지 다 차단당했습니다.
  깃허브는 쓰지 않기로 하셨으니, 남은 최선은 MEGA 입니다.

  MEGA 는 파일을 암호화해서 보관하므로 서버가 내용을 볼 수 없고,
  따라서 검사 자체를 하지 않습니다. 한글패치 배포에 오래 쓰여 온 곳입니다.

  그래도 불안하시면 "직접교체용.zip" 만 따로 다른 데 올려 두셔도 됩니다.
  그 파일은 실행 코드가 하나도 없어서 어디서도 막히지 않습니다.


■ 유저는 어떻게 설치하나요 (exe 기준)

  1. 링크에서 exe 를 내려받는다
  2. 더블클릭한다
  3. 1 을 누르고 Enter

  끝입니다. 압축 풀기도, 게임 폴더 찾기도 없습니다.
  권한이 필요하면 설치기가 알아서 물어봅니다.

  "Windows의 PC 보호" 경고는 [추가 정보] -> [실행] 로 넘어갑니다.
  코드 서명 인증서가 없어서 뜨는 것이고, 개인 제작 도구는 다 그렇습니다.

■ 번역을 고치려면

  tool\tr 폴더에 번역 데이터가 전부 들어 있습니다.

      tool\tr\glossary*.py    낱말 용어집 (Iron = 철)
      tool\tr\phrases*.py     문장 통째로 바꾸는 표
      tool\tr\desc\*.json     설명문
      tool\tr\dlg\*.json      NPC 대사
      tool\tr\meta\*.json     메뉴 / 버튼 같은 UI 문구

  고친 뒤 "3. 번역 고치고 다시 만들기.bat" 을 돌리면 됩니다.
  자세한 설명은 tool\0_README.md 에 있습니다.

  ※ 꼭 지켜야 할 것 ※
  tool\tr\meta\ 를 고쳤다면 새 게임을 한 번 시작해 보셔야 합니다.
  게임이 데이터를 불러오는 키로 쓰는 단어를 번역하면
  새 게임 시작 시 무한 로딩에 빠집니다. v1.0 때 실제로 겪은 문제입니다.
  확인 방법은 tool\0_README.md 에 적어 두었습니다.
