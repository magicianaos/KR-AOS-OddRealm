  bat 3개     내가 쓰는 것
  배포 폴더    남들에게 나눠줄 것
  tool 폴더    번역 데이터와 빌드 도구

  이게 다입니다.


■ 하고 싶은 게 뭔가요?

  내 PC에 한글패치를 깔고 싶다
      "1. 한글패치 설치.bat" 더블클릭

  영어로 되돌리고 싶다
      "2. 원본으로 되돌리기.bat" 더블클릭

  번역을 고쳐서 새 버전을 만들고 싶다
      "3. 번역 고치고 다시 만들기.bat" 더블클릭
      (Python 이 필요합니다. 없으면 어디서 받는지 알려줍니다)
      다 끝나면 "배포" 폴더의 파일이 자동으로 최신으로 바뀝니다

  남들에게 배포하고 싶다 (GitHub Releases)
      ..\0. 릴리즈\00_먼저읽기.md 를 보세요.
      ..\0. 릴리즈\릴리즈_올리기.bat 을 실행하면 올릴 파일 준비, 설명글 복사,
      GitHub 새 릴리즈 페이지 열기까지 해 줍니다.


■ 배포 폴더에 뭐가 있나요

  유저에게 줄 파일은 이것 하나입니다.

  OddRealm_한글패치_v1.0.3_스크립트판.zip  0.5MB
      압축을 풀고 ps1 우클릭 -> PowerShell에서 실행.
      실행 파일(exe)이 하나도 없고, 설치 과정을 직접 읽어볼 수 있습니다.
      게임 파일은 들어 있지 않고 번역문과 한글 폰트 차분 데이터만 있습니다.

  "OddRealm 한글패치 v1.0.3 (스크립트판)" 폴더는 위 zip 을 푼 것과 같습니다.

  ※ exe 설치기와 직접 교체용 zip 은 배포하지 않기로 했습니다.
     "3. 번역 고치고 다시 만들기.bat" 을 돌리면 이 둘이 다시 만들어져
     배포 폴더에 복사될 수 있습니다. 그대로 두거나 지우셔도 되고,
     Releases 에는 올리지 마세요. (zip/exe 는 .gitignore 로 Git 에서도 제외됩니다)


■ 배포는 어떻게 하나요

  GitHub Releases 에 올립니다. MEGA 는 쓰지 않습니다.

  구글 드라이브는 올린 파일을 검사해서 서명 없는 설치기를 지웠습니다.
  그래서 실행 파일이 없는 스크립트판 하나만 GitHub Releases 에 올리기로 했습니다.
  Releases 에서는 파일 이름의 한글이 지워지므로, 올릴 때는 영문 이름
  (OddRealm_KR_Patch_v1.0.3.zip)을 씁니다. 릴리즈 폴더의 bat 이 알아서 맞춥니다.


■ 유저는 어떻게 설치하나요

  1. Releases 에서 zip 을 내려받아 아무 폴더에나 푼다
  2. 한글패치_설치.ps1 을 우클릭 -> PowerShell에서 실행
     (Windows 11 은 [추가 옵션 표시] 안에 있습니다)
  3. 1 을 누르고 Enter

  자세한 설명과 안 될 때의 해결 방법은 zip 안의 읽어보세요.txt 에 있습니다.

■ 번역을 고치려면

  tool\tr 폴더에 번역 데이터가 전부 들어 있습니다.

      tool\tr\glossary*.py    낱말 용어집 (Iron = 철)
      tool\tr\phrases*.py     문장 통째로 바꾸는 표
      tool\tr\desc\*.json     설명문
      tool\tr\dlg\*.json      NPC 대사
      tool\tr\meta\*.json     메뉴 / 버튼 같은 UI 문구

  고친 뒤 "3. 번역 고치고 다시 만들기.bat" 을 돌리면 됩니다.
  자세한 설명은 tool\0_README.md 에 있습니다.

  ※ 꼭 지켜야 할 것 ※
  tool\tr\meta\ 를 고쳤다면 새 게임을 한 번 시작해 보셔야 합니다.
  게임이 데이터를 불러오는 키로 쓰는 단어를 번역하면
  새 게임 시작 시 무한 로딩에 빠집니다. v1.0 때 실제로 겪은 문제입니다.
  확인 방법은 tool\0_README.md 에 적어 두었습니다.
