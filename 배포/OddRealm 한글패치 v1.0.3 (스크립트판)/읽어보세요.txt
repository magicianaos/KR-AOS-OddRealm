================================================================
  Odd Realm 한글패치 v1.0.3
================================================================

■ 설치 방법

  1. 압축을 아무 폴더에나 풉니다. (게임 폴더가 아니어도 됩니다)
  2. 두 파일이 같은 폴더에 있어야 합니다.
       한글패치_설치.ps1
       patch.orkp
  3. "한글패치_설치.ps1" 을 마우스 오른쪽 클릭 →
     [PowerShell에서 실행] 을 누릅니다.
       · Windows 11 이라면 [추가 옵션 표시] 안에 있습니다.
  4. 게임 폴더를 자동으로 찾습니다. 못 찾으면 경로를 붙여넣으면 됩니다.
     (예: C:\Program Files (x86)\Steam\steamapps\common\Odd Realm)
  5. 1번(한글패치 설치)을 선택합니다.
  6. 게임을 실행합니다.

  ※ 게임이 실행 중이면 먼저 종료해 주세요.
  ※ "쓰기 실패" 가 뜨면 아래 "관리자 권한으로 실행하기" 를 보세요.
  ※ resources.assets 는 37MB라 적용에 20~40초 정도 걸립니다. 기다려 주세요.


■ 설치가 안 될 때

  · 오른쪽 클릭 메뉴에 [PowerShell에서 실행] 이 없다
      Windows 11 은 [추가 옵션 표시] 를 눌러야 나옵니다.
      그래도 없으면 아래 "명령으로 실행하기" 를 쓰세요.

  · 창이 떴다가 바로 닫힌다 / "이 시스템에서 스크립트를 실행할 수 없으므로"
      스크립트 실행이 정책으로 막힌 경우입니다. 아래 방법으로 실행하세요.

  · 관리자 권한으로 실행하기 / 명령으로 실행하기
      1) 시작 메뉴에서 "PowerShell" 을 검색합니다.
      2) [Windows PowerShell] 을 오른쪽 클릭 → [관리자 권한으로 실행].
      3) 아래 두 줄을 차례로 붙여넣고 Enter 를 누릅니다.
         (두 번째 줄의 경로는 압축을 풀어둔 폴더로 바꿔 주세요)

         Set-ExecutionPolicy -Scope Process Bypass -Force
         & "C:\내려받은\폴더\한글패치_설치.ps1"

  · "patch.orkp 파일이 없습니다"
      압축을 덜 풀었습니다. 두 파일을 같은 폴더에 두고 다시 실행해 주세요.


■ 원래대로 되돌리기

  같은 ps1 파일을 다시 실행하고 2번(원본으로 되돌리기)을 선택하면 됩니다.
  설치할 때 원본을 게임 폴더의 _KoreanPatch_Backup 안에 백업해 둡니다.

  백업이 없어졌다면 Steam에서도 복구할 수 있습니다.
  Steam → Odd Realm 우클릭 → 속성 → 설치된 파일 → 파일 무결성 검사


■ 들어있는 파일이 이게 전부입니다

  한글패치_설치.ps1   텍스트 파일. 메모장으로 열어 전부 읽을 수 있습니다.
  patch.orkp          번역문·폰트 차분 데이터. 실행되지 않는 데이터 파일입니다.
  읽어보세요.txt      이 문서
  라이선스/           폰트 라이선스

  실행 파일(exe)이 하나도 없습니다.
  설치 스크립트가 하는 일과 하지 않는 일은 ps1 파일 맨 위 주석에 적어 두었습니다.
  요약하면 네트워크 통신을 전혀 하지 않고, 게임 폴더 밖을 건드리지 않습니다.


■ 변경 내역

  v1.0.3  설치 스크립트가 Steam 라이브러리를 찾을 때, 존재하지 않는
          드라이브(예: E:)를 만나면 오류를 내고 멈추던 문제를 고쳤습니다.
          게임에 적용되는 번역 내용은 v1.0.1과 완전히 같습니다.
          실행 파일 확장자를 .cmd 에서 .bat 으로 바꿨습니다.

  v1.0.1  v1.0에서 새 게임 시작 시 "불러오는 중"에서 멈추던 문제를 고쳤습니다.
          원인은 UI 문구로 보이던 낱말 4개(Entities / Items / Party / Notifications)가
          실제로는 게임 데이터를 불러오는 내부 키로도 쓰이고 있었던 것입니다.
          번역하는 순간 해당 데이터 4종을 못 찾게 되어 멈춥니다.
          그래서 이 4개는 원문 그대로 두었습니다.

  ※ 이전 버전을 이미 설치했더라도 그냥 실행하면 됩니다.
     이전 백업을 찾아 원본으로 되돌린 뒤 새 패치를 적용합니다.

              완성형 11,172자 전체 + 호환 자모 + 한국어 문장부호 수록.


■ 아직 안 된 부분

  · 일부 메뉴와 시스템 메시지가 영문으로 남아 있습니다.
  · 개체 / 아이템 / 파티 / 알림 네 낱말은 위 이유로 영문입니다.
  · 정착민 이름, 지역 이름은 일부러 영문으로 두었습니다.
    게임이 조각을 조합해서 이름을 만드는 방식이라 번역하면 말이 안 됩니다.
  · 한글이 영문보다 조금 크게 보입니다. 픽셀 폰트 특성상
    한글을 알아볼 수 있게 하려면 이 크기가 필요합니다.


■ 번역 방침

  · 용어를 일관되게 맞췄습니다. Iron은 어디서든 "철" 입니다.
  · 한국어 어순을 반영했습니다. Build Stone Gate → "석재 관문 제작"
  · 조사를 받침에 맞춰 처리했습니다. "소 가죽으로", "흙으로"
  · 고유명사는 한글(영문)을 병기했습니다. 아르딘(Ardyn), 그위디르(Gwdir)
