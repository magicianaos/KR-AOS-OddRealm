Odd Realm 한글패치 v1.0.3

Steam 게임 Odd Realm 의 비공식 한국어 번역 패치입니다.
게임 원본 폰트에 한글이 아예 없어서 한글 폰트를 새로 만들어 넣었습니다.


▣ 다운로드

[여기에 MEGA 링크]

※ MEGA 에서 "앱을 설치하세요" 화면이 나오면
   [브라우저에서 다운로드] 를 누르시면 됩니다.


▣ 어떤 파일을 받아야 하나요

받는 곳에 파일이 세 개 있습니다. 하나만 받으시면 됩니다.

1) OddRealm_한글패치_v1.0.3.exe            ← 대부분 이거
   받아서 더블클릭하면 끝입니다.
   게임 폴더를 알아서 찾고, 원본을 백업해 둡니다.
   나중에 프로그램 안에서 영어로 되돌릴 수도 있습니다.

2) OddRealm_한글패치_v1.0.3_직접교체용.zip
   프로그램 실행이 꺼려지시면 이걸 받으세요.
   압축을 풀어서 나오는 OddRealm_Data 폴더를
   게임 폴더에 덮어쓰기만 하면 됩니다.

3) OddRealm_한글패치_v1.0.3_스크립트판.zip
   설치 과정을 직접 눈으로 확인하고 싶으신 분용입니다.
   안에 든 ps1 파일을 메모장으로 열면 전부 읽을 수 있습니다.


▣ 설치 방법 (1번 exe 기준)

1. 게임을 종료합니다
2. 받은 exe 를 더블클릭합니다
3. 1 을 누르고 Enter
4. 게임 실행

게임이 C:\Program Files 아래에 있으면 권한 창이 뜹니다. [예] 를 눌러 주세요.

"Windows의 PC 보호" 경고가 뜨면 [추가 정보] -> [실행] 을 누르시면 됩니다.
코드 서명 인증서가 없어서 뜨는 경고이고, 개인이 만든 도구는 다 그렇습니다.
찜찜하시면 2번이나 3번 파일을 받으세요.


▣ 원래대로 되돌리기

같은 exe 를 다시 실행하고 2 번을 고르시면 됩니다.
설치할 때 원본을 게임 폴더의 _KoreanPatch_Backup 안에 백업해 둡니다.

백업이 없어졌거나 2번 파일로 설치하셨다면
Steam -> Odd Realm 우클릭 -> 속성 -> 설치된 파일 -> 파일 무결성 검사
로도 영어 원본으로 돌아갑니다. 세이브는 지워지지 않습니다.


▣ 번역 범위

게임 내용   아이템 / 건물 / 작업 / 직업 / 기술 / 능력치 / 종족 / 상태이상
            툴팁 설명문 / NPC 대사 / 튜토리얼        10,329곳

인터페이스  메뉴 / 버튼 / 설정 / 알림 / 개체 정보창 / 방·작업 패널   943개

한글 폰트   완성형 11,172자 전체 + 호환 자모 + 한국어 문장부호


▣ 번역 방침

· 용어를 일관되게 맞췄습니다. Iron 은 어디서든 "철" 입니다
· 한국어 어순을 반영했습니다.  Build Stone Gate -> "석재 관문 제작"
· 조사를 받침에 맞춰 처리했습니다.  "소 가죽으로", "흙으로"
· 고유명사는 한글(영문) 병기입니다.  아르딘(Ardyn), 그위디르(Gwdir)


▣ 아직 안 된 부분

· 일부 메뉴와 시스템 메시지가 영문으로 남아 있습니다
· 정착민 이름과 지역 이름은 일부러 영문으로 두었습니다
  게임이 조각을 조합해서 이름을 만드는 방식이라 번역하면 말이 안 됩니다
· 개체 / 아이템 / 파티 / 알림 네 낱말은 영문입니다
  게임 내부에서 데이터를 불러오는 키로도 쓰이는 단어라,
  번역하면 새 게임이 시작되지 않습니다
· 한글이 영문보다 조금 크게 보입니다
  픽셀 폰트라 알아볼 수 있으려면 이 크기가 필요합니다
