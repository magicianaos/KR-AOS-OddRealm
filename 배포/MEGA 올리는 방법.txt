================================================================
  MEGA 에 올려서 배포하기
================================================================

■ 왜 MEGA 인가요

  구글 드라이브는 올리는 파일을 서버에서 검사합니다.
  서명 없는 설치기는 exe 든 스크립트든 악성코드로 오탐해서 지웁니다.
  (실제로 exe, bat+ps1, ps1 단독 세 가지 모두 차단당했습니다)

  MEGA 는 업로드한 파일을 암호화해서 보관합니다.
  서버가 내용을 볼 수 없으니 검사 자체를 하지 않습니다. 차단될 일이 없습니다.
  한글패치 배포에 오래 쓰여 온 곳이라 유저들도 익숙합니다.


■ 1. 계정 만들기

  https://mega.nz  ->  Create Account
  무료 계정으로 20GB 를 줍니다. 이 패치는 다 합쳐도 14MB 입니다.

  ※ MEGA 는 비밀번호를 잃어버리면 계정 복구가 안 됩니다.
     가입할 때 나오는 복구 키를 꼭 따로 저장해 두세요.


■ 2. 폴더 만들어서 통째로 올리기

  파일마다 링크를 따로 만들면 관리가 번거롭습니다. 폴더 하나로 묶으세요.

  1) 로그인 -> 왼쪽 Cloud drive
  2) 빈 곳 우클릭 -> New folder -> 이름:  OddRealm 한글패치
  3) 그 폴더로 들어가서, 이 "배포" 폴더에 있는 파일 3개를 끌어다 놓습니다

       OddRealm_한글패치_v1.0.3.exe               (3.5MB)
       OddRealm_한글패치_v1.0.3_직접교체용.zip     (8.7MB)
       OddRealm_한글패치_v1.0.3_스크립트판.zip     (0.5MB)

     ※ 이 안내 파일과 배포글 파일은 올리지 않습니다.


■ 3. 링크 만들기  ← 여기가 제일 중요합니다

  1) Cloud drive 로 나와서 "OddRealm 한글패치" 폴더를 우클릭
  2) Share -> Get link  (또는 Manage link)
  3) 반드시  "Link with key"  쪽을 고릅니다

     MEGA 링크는 두 가지가 있습니다.
       Link without key : 열쇠가 빠져서 남들이 못 받습니다
       Link with key    : 이걸 공유해야 합니다  ←

     주소 중간에 # 뒤로 긴 문자열이 붙어 있으면 열쇠가 포함된 것입니다.
     예)  https://mega.nz/folder/AbCdEfGh#xxxxxxxxxxxxxxxxxxxxxx

  4) Copy 를 눌러 주소를 복사합니다

  ※ 링크를 만든 뒤 직접 시크릿 창(Ctrl+Shift+N)에서 열어 보세요.
     로그인 없이 파일 목록이 보이면 제대로 된 것입니다.


■ 4. 배포글 올리기

  같은 폴더의 "배포글 (복사해서 붙여넣기).txt" 를 열어
  맨 위의 링크 자리에 3번에서 복사한 주소를 넣고,
  카페나 커뮤니티에 그대로 붙여넣으시면 됩니다.


■ 5. 새 버전을 올릴 때

  1) "3. 번역 고치고 다시 만들기.bat" 으로 새 파일을 만듭니다
  2) MEGA 의 같은 폴더에 새 파일을 올립니다
  3) 옛 버전 파일은 지우거나 "구버전" 하위 폴더로 옮깁니다

  폴더 링크는 그대로 살아 있습니다. 공지 글의 주소를 고칠 필요가 없습니다.
  이게 폴더로 묶어서 공유하는 가장 큰 이점입니다.


■ 알아두실 점

  · 무료 계정은 하루 전송량 제한이 있습니다.
    받는 사람이 아주 많아지면 잠시 "전송 한도 초과" 가 뜰 수 있습니다.
    몇 시간 지나면 풀리고, 받는 사람이 MEGA 에 로그인하면 대개 해결됩니다.
    한도가 자주 걸리면 같은 파일을 다른 곳에도 올려 두고
    배포글에 링크를 두 개 적어 두시면 됩니다.

  · MEGA 는 처음 받는 분들이 "앱 설치하라" 는 화면을 만날 수 있습니다.
    그 창에서 "브라우저에서 다운로드" 를 고르면 됩니다.
    배포글에 이 안내를 이미 적어 두었습니다.
